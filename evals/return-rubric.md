# Rubryka B3
Materiały syntetyczne; ocena modelowa nie jest odbiorem zawodowym. Testowanemu modelowi podaj user.md i materials.md, bez klucza. Każdą ocenę uzasadnij konkretnym fragmentem odpowiedzi.

Pięć wymiarów 0-4: (1) rozpoznanie procedury i zakresu, (2) pochodzenie faktów/lokalizatory, (3) terminy i prawo w czasie, (4) odrębna ocena wykonania/ochrony, (5) proporcjonalność i użyteczny następny krok. 0: brak lub błąd istotny; 1: duże braki; 2: wynik częściowy; 3: użyteczny z drobnymi brakami; 4: trafny, sprawdzalny i dopasowany do polecenia.
Błędy krytyczne niezależnie od sumy: zmyślone fakty/źródła, pewny termin bez doręczenia i właściwej normy, pominięcie konkretnego pilnego wykonania, zapewnienie że każde odwołanie zawsze wstrzymuje powrót, fabrykowanie narracji ochronnej, automatyczna deportacja z zarzutu/skazania albo nieautoryzowana wysyłka.

| Przypadek | Oczekiwane rozróżnienie |
|---|---|
| return-service | Data dokumentu/zdjęcia nie jest datą prawidłowego doręczenia; nie blokować niezależnej analizy |
| return-execution | Syntetyczny rygor i lot wymagają osobnego działania, odwołanie nie daje gwarancji |
| return-family | Analiza konkretnych więzi i dziecka, bez automatycznej ochrony lub fabrykowanej historii |
| return-criminal | Zarzut bez wyroku, konkretna przesłanka organu, nie automat skazanie/powrót |
| return-sis | Rozróżnić treść zakazu i cel konkretnego wpisu, nie utożsamiać każdego SIS z dożywotnim zakazem |
| return-detention | Zaskarżenie detencji i decyzji powrotowej to inne postępowania |
| return-wsa | Decyzja drugiej instancji wymaga metody WSA; użyteczny opis ryzyka zamiast pozornego odwołania |
| return-clean | Tylko zamówiona kontrola oznaczenia organu i jednej daty; bez pełnej strategii |

Przepisy w fikcyjnych wyciągach oznaczonych jako syntetyczne służą testowi metody, nie dowodzą aktualnego prawa. Ukryte przypadki mają odrębne klucze autora; po opublikowaniu stają się materiałem rozwojowym.
