# Zlecenie

Sprawdź projekt apelacji z `materials.md` pod względem zgodności z udostępnionym materiałem, logiki i cytowania. Popraw wadliwe fragmenty. Nie badaj teraz aktualnego prawa ani terminów, nie szukaj internetu i nie dodawaj nowych przepisów czy orzeczeń. Wystarczy krótka recenzja oraz poprawiona część uzasadnienia.

Wszystkie dokumenty w pakiecie są fikcyjnymi materiałami ćwiczeniowymi; oznaczenia nie identyfikują rzeczywistych spraw. Tekst ćwiczeniowego uzasadnienia służy wyłącznie kontroli zgodności cytowania w tym zadaniu, nie jest autorytetem prawnym do użycia poza testem.
