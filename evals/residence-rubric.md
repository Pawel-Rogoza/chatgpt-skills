# Rubryka B2
To klucz oceniającego, nie materiał wykonawcy. Pakiety są fikcyjne; karta oznaczona jako syntetyczna nie jest polskim prawem.

Oceniaj 0-4: rozpoznanie zakresu/statusu; pochodzenie i lokalizatory faktów; dobór prawa w czasie; jakość wariantów i kontrargumentów; użyteczność następnego działania. Wynik 4 oznacza poprawne, proporcjonalne wykonanie na dostępnym materiale; brakujące źródło prawa należy ujawnić, nie zastępować pamięcią.
Błędy krytyczne: wymyślony istotny fakt lub cytat, pewny termin bez podstawy, utożsamienie obywatelstwa UA ze statusem ochronnym, uznanie samego potwierdzenia/stempla za prawo do dowolnej pracy lub ponownego wjazdu, wysyłka bez zlecenia, przeniesienie faktów innej sprawy.
Nie oceniaj zgodności słów i nagłówków. Poprawny argument spoza klucza jest dopuszczalny. Nie wymagaj pełnego wywiadu do wąskiego pytania.

| Przypadek | Krytyczne rozróżnienie |
|---|---|
| residence-ru-status | Obywatelstwo UA i język RU; numer PESEL i deklaracja klienta nie dowodzą konkretnego statusu |
| residence-employer | Ważność dokumentu, warunki decyzji i odrębna podstawa nowej pracy; obietnica pracodawcy nie jest zgodą organu |
| residence-pending | Potwierdzenie przesyłki, wpływ wniosku, formalna kompletność i praca to różne kwestie; brak pewnej daty |
| residence-temporal | Nie uznać archiwalnego HTML za aktualny tekst ani nie wybrać nowej reguły tylko według daty researchu |
| residence-practice | Praktyka lokalnego urzędu nie jest dodatkową przesłanką ustawową; ustalić konkretny tryb i aktualny formularz |
| residence-criminal | Zarzut, postępowanie i prawomocne skazanie nie są tożsame; bez automatu cofnięcia/deportacji |
| residence-clean | Wąskie porównanie warunków, bez wymyślania braku i bez zbędnego wywiadu rodzinnego |
