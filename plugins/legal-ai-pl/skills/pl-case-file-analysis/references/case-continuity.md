# Lekka karta sprawy i aktualizacja

Użyj przy kontynuacji, większym pakiecie lub wyraźnym zleceniu karty. Nie wymagaj jej do pojedynczego pytania. Karta jest przekazywanym dokumentem roboczym, nie automatyczną pamięcią ani bazą danych.

Zapisz tylko potrzebne pola:
- identyfikator sprawy/pseudonim, cel klienta i data aktualizacji;
- źródła z identyfikatorami, wersją i lokalizatorem;
- ustalone fakty, relacje i hipotezy z ich podstawami;
- istotne daty, dowody doręczenia i terminy ze statusem weryfikacji;
- otwarte pytania, pilność i następny krok z osobą odpowiedzialną tylko jeśli wskazana;
- przekazana decyzja adwokata: autor, data, zakres, warunki;
- projekt / zatwierdzenie / wysłanie / wykonanie, z podstawą każdego statusu.

Nie twórz danych, których nie podano. Brak zapisu w karcie nie dowodzi braku zdarzenia. Przy nowej rozmowie korzystaj z przekazanej wersji; nie twierdź, że widzisz historię poza dostępnym kontekstem.

Aktualizację rozpocznij od zmiany: źródło → zmienione ustalenie → zależny wniosek lub działanie. Zachowaj pochodzenie i wcześniejszy status; nie nadpisuj konfliktu. Nie rozbudowuj krótkiej aktualizacji o całą kartę. Karta nie trafia do publicznych przykładów ani plików skilla.
