# Większy pakiet i porównanie dowodów

Stosuj tylko, gdy objętość, wersje lub zakres odczytu utrudniają kontrolę materiału.

- Zachowuj stabilne identyfikatory dokumentów między partiami. Krótki rejestr ma odróżniać: dostępny, odczytany (zakres), nieczytelny i nieprzekazany. Wynik wyszukiwania fragmentów nie oznacza odczytu całego tomu.
- Pracuj według zagadnień ważnych dla celu. Zapisz dla każdego roboczy wniosek, źródła wspierające i przeciwne oraz zakres wymagający doczytania. Przed łączeniem partii wróć do pełnego kontekstu kluczowych fragmentów zamiast scalać same streszczenia.
- Przy porównaniu wypowiedzi wybierz wspólną tezę: kto, co, kiedy, skąd wie. Różne zegary, punkty obserwacji i znaczenia słów mogą wyjaśniać rozbieżność, ale same możliwości nie rozstrzygają jej. Zanotuj pytanie lub dokument pozwalający ją wyjaśnić.
- Duplikat i poprawiona wersja nie zwiększają liczby niezależnych źródeł. Ustal relację zastąpienia z treści lub metadanych pochodzenia; gdy nie jest jasna, zachowaj obie wersje i nazwij niepewność. Po zmianie wersji sprawdź wnioski, które zależały od starej kwoty, daty lub relacji.
- Kończ etap jawnym zakresem. Gdy nie można przeczytać reszty, dostarcz część użyteczną już teraz i listę nierozstrzygniętych zależności. Nie dopisuj „akta kompletne” dlatego, że wykorzystano wszystkie udostępnione pliki.
