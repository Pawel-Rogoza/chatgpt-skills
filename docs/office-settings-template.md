# Ustalenia kancelarii do przekazania modelowi

To pusty formularz. Nie jest zatwierdzonym cennikiem ani polityką. Wypełnij poza publicznym repozytorium i przekaż potrzebną część przy zadaniu. Nie wpisuj tutaj danych klientów.

| Ustalenie | Wartość | Zatwierdzający i data | Zakres / ważność |
|---|---|---|---|
| Nadawca wiadomości i rola | Nie podano | Nie podano | Nie podano |
| Forma zwracania się do klientów | Nie podano | Nie podano | Nie podano |
| Godziny i kanał kontaktu | Nie podano | Nie podano | Nie podano |
| Cena i zakres konkretnej usługi | Nie podano | Nie podano | Nie podano |
| Sposób umawiania i potwierdzania terminu | Nie podano | Nie podano | Nie podano |
| Wymagane dokumenty na określony etap | Nie podano | Nie podano | Nie podano |
| Osoba / procedura pilnego przekazania | Nie podano | Nie podano | Nie podano |
| Zasady danych i używanego środowiska | Nie podano | Nie podano | Nie podano |

Przykładowe zlecenie: „Pracuję w kancelarii bez uprawnień adwokackich. Przygotuj odpowiedź do klienta po rosyjsku na WhatsApp. Poniżej wiadomość i aktualne zatwierdzone ustalenia. Jeśli potrzebna jest nowa decyzja prawna, krótko zaznacz mi to osobno”.

Brak wartości oznacza brak danych. Model nie ma na tej podstawie wymyślić stawki, terminu ani zatwierdzenia. Zatwierdzenie konkretnej oceny sprawy przekazuj osobno z zakresem i warunkami.
